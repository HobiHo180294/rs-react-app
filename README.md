# Gallery

## Setting Up the API

1. **Register on Unsplash**:  
   Begin by visiting [Unsplash](https://unsplash.com/) and signing up to obtain your API `ACCESS_KEY`.

2. **Configure Environment Variables**:  
   Create a `.env` file in the root directory of your project. Populate it by following the structure provided in the `.env.template`.

3. **Start the Development Server**:  
   Once the above steps are completed, initiate the development server using the command:
   
   ```bash
   npm run dev
   ```
